## Wat is Claude Code?

Anthropic heeft Claude Code gelanceerd — een AI-agent die direct in je terminal draait. Anders dan traditionele code-assistants die suggesties geven, kan Claude Code zelfstandig taken uitvoeren: bestanden aanmaken, code schrijven, tests draaien en git commits maken.

## Hoe werkt het?

Je installeert Claude Code via npm en start het in je projectmap. Vervolgens beschrijf je in natuurlijke taal wat je wilt: "Voeg een dark mode toggle toe aan de header" — en Claude Code plant de aanpak, schrijft de code en test het resultaat.

## Voor wie is het?

Claude Code is bedoeld voor ervaren developers die comfortabel zijn met de terminal. Het is geen vervanging voor een IDE, maar een krachtige aanvulling. De tool begrijpt grote codebases en kan complexe refactoring-taken uitvoeren die meerdere bestanden beslaan.

## Prijzen

Claude Code werkt op basis van API-gebruik. Er is geen vast maandabonnement — je betaalt per token. Voor gemiddeld gebruik komt dit neer op enkele euro's per dag.
